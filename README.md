# WFC Proposal Builder (website copy)

Fill in one form, watch the proposal build beside it, then save it as a PDF. The proposal is the solution and client education only; pricing lives
in a separate Quotation tab that is not released yet. Everything runs in your browser (Edge or Chrome) and nothing is uploaded.

**Open it:** https://zzllchen.github.io/wfc-proposal-builder-web/

- **Save PDF** opens your browser's print window: tick *Save as PDF* and untick *Headers and footers* under *More settings*.
- **New from a brief** (the **+** tab) works out the solution from a client description, a plain site layout and one raw pallet photo.
- **AI** (top bar): optional. Paste your own Claude API key to let Claude read photos and draw the layout. Without a key the built-in rules still work.
  The key is saved in this browser only and is sent only to Anthropic.
- Work is saved in this browser. **File, Save project** keeps a `.json` copy you can send or reopen.
- This website copy has no sample client and shows a relative price index instead of the real prices. The full tool (clean PDF, PowerPoint export,
  sample project) runs from `Start.bat` on a PC with Python.
